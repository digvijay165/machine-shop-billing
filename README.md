# ForgeFlow — Workshop Billing

A simple browser-based billing site for machine parts and workshop services.

## Features

- Create, edit, print, and track customer bills.
- Search saved parts by part number, name, brand, and imported spreadsheet fields.
- Import item lists from `.xlsx` or `.csv` files.
- Share a bill summary through email or WhatsApp, or print it to PDF.
- Export invoice records as CSV and back up or restore local data.

## Data and privacy

Invoices, business settings, and saved items are stored in the browser on the device where the site is used. Imported spreadsheets are processed in the browser and are not uploaded by the site. Use **Business settings → Download backup** to move data to another device.

Email and WhatsApp actions open a pre-filled message. To send the complete bill, print or save it as a PDF and attach it to the message.

## GitHub Pages

This is a static site. Enable GitHub Pages from the repository’s `main` branch and root folder to publish `index.html`.
